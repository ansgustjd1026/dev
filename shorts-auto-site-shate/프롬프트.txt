완료된 주요 기능
- 프로필의 화면 모드와 사이트 언어는 저장 버튼을 눌러야 적용된다.
- 저장 후 프로필 첫 화면으로 이동하지 않고 현재 설정 탭에 남는다.
- 영상 방식에 따라 관련 설정만 표시된다.
  - 자동 생성: 자동 생성 스타일, 배경 배속, 배경 재생 방향
  - 내 배경 랜덤: 배경 배속, 배경 재생 방향
- 영상 스타일은 시네마틱 실사, 2D 애니, 2D 흑백, 3D 애니, 동물 캐릭터, 웹툰이 있으며 이미지 생성과 실제 제작 프롬프트에 반영된다.
- 웹툰 스타일은 10~20대가 공감할 연애·입시·가족·친구 관계 소재를 자연스럽게 사용하도록 설정되어 있다.
- 2D 흑백 스타일도 이미지 프롬프트에 적용되도록 수정됐다.
- 대본은 `gpt-5.6-terra`, 강조 표시는 `gpt-5.6-luna`를 사용한다.
- 대본은 사용자가 입력한 주제를 최우선으로 유지한다. 주제에 없는 가족 갈등, 돈 문제, 불륜, 상속 등을 임의로 추가하지 않는다.
- 대본 도입부에 인물 나이가 반복해 나오지 않도록 제한했다.
- 자동 제작의 오류 표시와 상태 UI를 정리했다.
- 관리자에서 요금제별 월간 크레딧을 설정할 수 있고, 가격 페이지와 실제 크레딧 제한에 함께 반영된다.

YouTube 상태
- YouTube 계정 연결, 자동 업로드 기능은 유지한다.
- 과거 채널 영상, 시청자 국가·연령·성별, 최근 영상 등을 분석하는 기능은 완전히 제거했다.
- 제거된 항목: 분석 화면, 분석 API, 연결 직후 자동 분석, 대본 프롬프트 반영, 분석 결과 UI, Analytics OAuth 권한.
- `app/api/youtube/audience`는 삭제되어 404가 정상이다.
- 기존 Supabase 분석 테이블은 앱에서 더 이상 읽거나 쓰지 않는다.
- 실제 DB 테이블까지 지우려면 `supabase/remove_youtube_audience_insights.sql`을 Supabase SQL Editor에서 실행하면 된다. 이 작업은 아직 DB 관리자 연결 정보가 없어 자동 실행하지 못했다.
- Google OAuth redirect URI 오류를 수정했다.
  - Render 내부 주소 localhost:10000 대신 `APP_BASE_URL` 또는 `RENDER_EXTERNAL_URL`을 사용한다.
  - Google Cloud OAuth Redirect URI:
    https://shate-37cj.onrender.com/api/youtube/callback
    https://shate-37cj.onrender.com/api/toss/youtube/callback
  - 관련 구현: lib/auth/public-origin.ts

- Toss 등록용 이미지들은 `toss-app/screenshots/`에 있다.

배포 및 환경
- Render는 GitHub main 푸시를 배포 대상으로 쓴다.
- Render 환경 변수에는 Supabase, OpenAI, Google OAuth 값 등이 설정돼 있다.
- 공개 도메인을 변경하면 `APP_BASE_URL`을 새 공개 origin으로 지정하고 Google OAuth 콜백 주소도 함께 바꿔야 한다.
- `.env.local` 등 민감정보는 출력하거나 Git에 추가하지 마라.
