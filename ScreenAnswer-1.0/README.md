# ScreenAnswer 1.0

Windows에서 화면 또는 선택한 텍스트를 AI에 전달하고 말풍선·트레이·Caps Lock LED로 결과를 확인하는 앱입니다.

## 실행

`Run-ScreenAnswer.bat`을 실행합니다. 트레이 모니터 아이콘을 왼쪽으로 한 번 클릭하면 설정 홈이 열립니다. 오른쪽 메뉴는 설정·종료입니다.

- 화면 캡처: 단축키, 버튼 없이 원 두 바퀴, 연속 클릭을 한 박스에서 설정합니다. 캡처 사용이 켜져 있어야 마우스 동작도 작동합니다.
- 다중 모니터: 단축키는 활성 창이 있는 모니터, 마우스 동작은 동작한 위치의 모니터를 캡처합니다. 왼쪽·위쪽에 배치한 보조 모니터도 지원합니다.
- 텍스트 선택: 자동 전송 대기 시간, 선택 위치의 말풍선과 투명도를 설정합니다. 클립보드 질문 기능은 없습니다.
- 말풍선은 답변의 모든 줄과 문단을 표시합니다. 화면 높이를 넘는 답변은 말풍선 위에서 마우스 휠이나 스크롤 막대로 끝까지 볼 수 있습니다.
- 트레이 오른쪽 메뉴의 `최근 원문과 답변`에서 실제로 전송한 텍스트를 확인하고 복사할 수 있습니다. 최근 원문은 앱 실행 중 메모리에만 보관하며 파일이나 진단 로그에는 저장하지 않습니다.
- AI: 자유 질문·참거짓·객관식·번역·요약 프롬프트를 각각 저장합니다. 직접 수정과 추가 요청을 지원합니다.
- 기본 프롬프트: 각 작업의 대상·출력 형식·정보 부족 시 처리 방법을 지정합니다. 질문·판별 작업은 여러 문제 중 가장 위 문제만 답하고, 번역·요약은 원문을 풀거나 없는 내용을 추가하지 않습니다.
- 참거짓·객관식은 AI가 답만 반환하고 앱이 LED 횟수를 연결합니다. 나머지 작업은 프롬프트에서 LED 1~9번을 지시합니다. 잘못된 응답은 실패 알림으로 처리합니다.
- 번역: 별도 모델과 대상 언어를 설정합니다. 기본은 `gpt-4.1-mini`이며 참고 자료 검색·첨부를 생략합니다.
- 텍스트 번역 말풍선은 생성된 내용부터 표시하고, 완료 후 전체 번역을 표시합니다. 번역 중에는 완료 LED를 작동시키지 않으며 연결이 끊기면 오류를 표시합니다.
- 참고 자료: 파일 직접 첨부 또는 같은 API 프로젝트의 지식 저장소 검색을 사용합니다.

Caps Lock LED 알림은 실제 키 상태를 전환하고 원래 상태로 복원합니다. 설정과 암호화된 API 키는 `%LOCALAPPDATA%\ScreenAnswer`에 저장되며 이 프로젝트에 포함하지 않습니다.

자동 텍스트 전송 직전에 현재 선택과 활성 창을 다시 확인합니다. 기본 프롬프트의 완료 LED 횟수는 결과 알림의 기본 알림 설정을 따르며, 직접 작성한 프롬프트의 LED 지시는 유지합니다.

설정 파일이 손상됐거나 값이 올바르지 않으면 기본 설정으로 시작하고 트레이에 알립니다. 기존 파일은 같은 설정 폴더의 `settings.recovery-날짜-시간.json`에 백업합니다. 기본값으로 복구된 경우 API 키와 원하는 설정을 다시 등록하세요. 백업 파일에는 기존 암호화된 API 키가 포함될 수 있습니다.

오류 진단 로그는 `%LOCALAPPDATA%\ScreenAnswer\diagnostics.log`에 저장합니다. 발생 단계, 오류 종류·번호와 앱 소스의 줄 번호만 기록하며, API 키·화면·질문·답변·예외 메시지·문서 경로는 기록하지 않습니다. 로그는 파일당 128KB, 이전 파일 2개까지 유지합니다.

참고 파일은 작은 단위로 읽어 Base64로 변환하고 요청 JSON도 나누어 인코딩해, 큰 파일 전송 시 메모리 복사를 줄입니다. 원본 파일과 요청 내용의 임시 사본은 디스크에 저장하지 않습니다. 파일을 읽는 동안 크기가 바뀌어도 파일별·전체 용량 제한을 다시 확인합니다.

## 개발과 빌드

`app.py`는 화면·설정 UI와 이벤트를 연결합니다. API 요청은 `api_client.py`, 설정 검증·저장은 `settings_store.py`, API 키 암호화는 `credentials.py`, 단축키 등록은 `hotkeys.py`에서 처리합니다. 이 핵심 모듈들은 GUI 패키지 없이도 테스트할 수 있습니다.

`Build-ScreenAnswer.bat`이 Python 가상환경과 의존성을 준비하고 `dist/ScreenAnswer-1.0.exe`를 생성합니다. Python 3.10 이상이 필요합니다.

테스트:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s src/tests
```

Git에는 `src`, 의존성 목록, 빌드 설정, 실행·빌드 배치 파일과 이 문서를 올립니다. `.venv`, `dist`, 빌드 캐시, 개인 설정과 API 키는 제외합니다. 실행 파일 배포는 GitHub Release 등 별도 첨부로 관리할 수 있습니다.
